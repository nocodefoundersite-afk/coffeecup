# CoffeeCups — Interactive Product Studio

A responsive product website for reusable coffee cups, thermal mugs and
bottles, including an interactive 3D personalisation studio, product-specific
hero sections, scroll motion and a cinematic homepage film.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Deploy on Netlify

Connect this repository to Netlify. The included `netlify.toml` automatically
uses:

- Build command: `pnpm build`
- Publish directory: `out`
- Node.js: `22.13.0`
- pnpm: `11.25.0`

No environment variables are required for the current site.
